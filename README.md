# FlatExpenseSplitter 🏠

A simple Python mini project to calculate and split flat expenses equally among roommates.

## 🚀 Features
- Takes rent, food, and electricity expenses as input
- Calculates total expense
- Splits the amount equally among people
- Displays output rounded to 2 decimal places

## 🛠️ Tech Stack
- Python 3

## ▶️ How to Run
1. Clone the repository
   ```bash
   git clone https://github.com/Krutika-Joshi/FlatExpenseSplitter.git
2. Navigate into the project folder:
   ```bash
   cd FlatExpenseSplitter
3. Run the program:
   ```bash
   python flat_expense_splitter.py
